# finn
AI-powered financial investment intelligence agent
## Product Vision

FINN is an inbox that is usually empty: an AI-powered investment intelligence agent that surfaces only what matters.
Its home screen is a single feed of important updates, ranked by relevance and impact.
Routine announcements are collapsed into a summary so investors can focus on meaningful developments.
Every update includes an "Ask FINN" option that opens a contextual conversation for deeper analysis.
Every factual claim is traceable to its original source, building transparency and trust.
